# Cozy — Digital Playground

Авторское портфолио Ильи (Cozy), собранное на React + Vite с интерактивными 3D-сценами на Three.js / React Three Fiber.

## Запуск

```bash
npm install
npm run dev
```

## Production-сборка

```bash
npm run build
npm run preview
```

## Структура

- `src/App.jsx` — секции сайта, навигация, анимации и 3D-сцены.
- `src/styles.css` — адаптивная типографика, сетка, темы и состояния интерфейса.
- `src/main.jsx` — точка входа React.

Экспериментальные сцены — учебные визуальные исследования, а не коммерческие кейсы. Сайт рассчитан на десктоп и мобильные экраны; для пользователей с настройкой reduced motion предусмотрено уменьшение анимации.
